# Easy Save Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Kullanıcı uygulamayı onayladı; bu oturumda doğrudan uygulanacak.

**Goal:** Genel veri kabını Easy Save ile saklamak; nesnelerin başlangıçta kendi durumunu çekmesini sağlamak.
**Architecture:** ISaveStorage dosya sınırıdır. GameSaveService oyun snapshot'ını toplar; SaveableEntity kendi durumunu çeker, DynamicObjectSpawner eksik örnekleri oluşturur.
**Tech Stack:** Unity 6000.5.9f1, C#, VContainer 1.19.0, kurulu Easy Save 3.
**Spec:** [Onaylı tasarım](../specs/2026-11-14-easy-save-design.md)

## Global Constraints

- Eski `Saves` kayıtlarına dokunma; yeni kayıt kökü `SavesV2`.
- GameSaveData oyun/Unity/ES3 alanı taşımaz; yeni bağımlılık ekleme.
- Restore olayı yok; bir nesne, başlangıcında kendi verisini çeker.
- Kullanıcının mevcut değişikliklerini koru; commit/worktree oluşturma gerektirmeyen mevcut Editor oturumunda çalış.

## Review Focus

- Henüz başlamamış kapalı nesnenin verisi yeniden kayıtta korunmalı.
- Tekrar spawn ve yinelenen kimlikler sessiz veri kaybına yol açmamalı.
- ES3 object sözlükleri gerçek durum tiplerini ve envanteri korumalı.
